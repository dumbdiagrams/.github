# Dumb Diagrams

**A little opinionated. A lot clearer.**

We build tools for architecture diagrams as code. Describe a system in a
readable `.dgm` file, let the engine handle layout and routing, then review and
refine it in a local Studio.

- **[dumb-diagrams](https://github.com/dumbdiagrams/dumb-diagrams)**: the engine, CLI, and Studio
- **Get started:** `npm install -g create-dumb-diagrams && dumbdiagrams init`

Issues, ideas, and pull requests are welcome in the repository above.
